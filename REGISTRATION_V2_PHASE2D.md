# Registration V2 — Phase 2D (existing member claim)

This incremental patch allows an existing MHAV member to link a guest application using both a valid 24-hour email verification link and an authenticated session for the matching account. It also keeps the already-existing administrator registration button unchanged.

## Install

Extract into the project root on `feature/registration-v2`.

```powershell
python manage.py check
python manage.py test apps.planning.tests_account_claim_existing
python manage.py test
```

No migration required.

## Scope and caveats

- The existing new-account activation process is unchanged.
- The emailed claim URL is generated by the existing `request_account_invite` view. Users must request the link from the application thank-you/session flow.
- The link expires after 24 hours; it is not single-use before an account is linked.
- Further work: account claiming without the original guest session, comprehensive browser flow, and full notification/season-planning integration.
